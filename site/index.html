goatrodeo

Games and toys that run on a goat data fabric.

Each one is fun to play and publishes real events while you play it. Air Defenders is the first: a browser arcade game, solo or co-op, that runs on a laptop with one Go command.

What it is

One small Go program with three web pages inside it. One container, one process, one SQLite file. None of it is needed to run a goatnet; it sits beside goatcore, which builds the goatnet, and goatstuff, which holds the surfaces you would watch it from.

Solo

Air Defenders

Steer interceptors into incoming drones before they reach the ground. Three fire modes: steered by hand, proximity-fused, or seeking on their own. When a wave ends, the sky shows the path of every shot.

Co-op

Up to 8 players, one room

One shared score and one set of lives; each player gets a launcher in their own color. The server owns the game and steps it 30 times a second; browsers send key presses and draw what they are told.

Fabric

Events while you play

On a goatnet, four moments in the game loop are published onto the Zenoh fabric: a radar detection, a launch, an intercept, and a drone reaching the ground.

Shared high scores, and a board that still draws offline

High scores are shared between everyone who can reach the server and arrive live over Server-Sent Events. The browser keeps its own copy, so the board still draws when the network is away. The copy of the game on this page has no server behind it, so its scores stay in your browser.

Design: airdefenders-leaderboard.md

Radars only show you part of the sky

You have one launcher, a handful of interceptors and three ways to fire them. Later waves add a second launcher, a siren that sends you running for the bunker, and a relief wave in which camels handle the air defense.

8 bots that play like people

Add ?bot=<name> to the co-op address and that browser tab plays by itself. A bot reads the same snapshots a person sees and sends the same key presses, so the server cannot tell the two apart. They are eight settings of one small loop in mp.html, tuned so that between them they press every button in the game.

A traffic generator with a scoreboard

The /demo page fills the room with all eight bots from one tab and plays until you close it. With the publisher switched on (ZENOH_PUBLISH=1) on a goatnet, the game publishes these keys, and the command in the page header tails them. On a laptop the publisher is off and the game plays on its own.

Run it

You need Go (the version in go.mod) and a browser. DB_PATH puts the high-score database in a local file, AD_DEMO_UNGATED=1 opens the bot demo page without a sign-in, and SITE_ID is the name the game would publish under.

On a laptop

$ git clone https://github.com/USAREUR-AF/goatrodeo
$ cd goatrodeo/ops/serve/airdefenders
$ DB_PATH=./local-scores.db AD_DEMO_UNGATED=1 \
    SITE_ID=zagros go run .

On a goatnet

The role and playbooks in ops/ansible/ deploy Air Defenders behind the goatnet's sign-in, from an assembled goatcore tree with this repository's ops/ copied over it. The image is built by airdefenders-image.yml and published as ghcr.io/usareur-af/airdefenders.

Add a game or a toy

Two house rules: it runs on a laptop with the fabric switched off, and it publishes something real when the fabric is on. Air Defenders is the pattern to copy: the service in ops/serve/<name>/, its schemas in ops/zenoh-trial-peers/, its captures and how they were made in docs/media/. Read CONTRIBUTING.md first.
